# 📚 About this file

This dataset contains information from a higher-education institution about various variables related to undergraduate students — demographic data, socioeconomic factors, and academic performance — with the aim of investigating the impact of these factors on student dropout and academic success.

---

## 🧾 Included variables

- 💍 **Marital status:** (Categorical) The student's marital status.
- 📝 **Application mode:** (Categorical) The application method used by the student.
- 🔢 **Application order:** (Numeric) The order in which the student submitted their application.
- 🎓 **Course:** (Categorical) The degree program or major the student is enrolled in.
- 🌞🌜 **Daytime/evening attendance:** (Categorical) Indicates whether the student attends day or evening classes.
- 🧾 **Previous qualification:** (Categorical) Degree or prior training before admission.
- 🌍 **Nationality:** (Categorical) The student's nationality.
- 👩‍🏫 **Mother's qualification:** (Categorical) Mother's educational level.
- 👨‍🏫 **Father's qualification:** (Categorical) Father's educational level.
- 👩‍💼 **Mother's occupation:** (Categorical) Mother's occupation.
- 👨‍💼 **Father's occupation:** (Categorical) Father's occupation.
- 🧳 **Displaced:** (Categorical) Indicates whether the student is a displaced person.
- ♿ **Special educational needs:** (Categorical) Whether the student has special educational needs.
- 💸 **Debtor:** (Categorical) Whether the student has outstanding debts.
- ✅ **Tuition payments up-to-date:** (Categorical) Whether tuition payments are current.
- ⚧ **Gender:** (Categorical) The student's gender.
- 🎓 **Scholarship recipient:** (Categorical) Indicates whether the student receives a scholarship.
- 🎂 **Age at enrollment:** (Numeric) Student's age at the time of enrollment.
- 🌐 **International:** (Categorical) Indicates whether the student is of international origin.
- 🔁 **Curricular units 1st sem (credited):** (Numeric) Number of units credited in the 1st semester.
- 🧾 **Curricular units 1st sem (enrolled):** (Numeric) Number of units enrolled in the 1st semester.
- 📝 **Curricular units 1st sem (assessed):** (Numeric) Number of units assessed in the 1st semester.
- ✔️ **Curricular units 1st sem (passed):** (Numeric) Number of units passed in the 1st semester.
